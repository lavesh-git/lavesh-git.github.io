# 3.1.2 Struct vs Class

In C++, a structure works the same way as a class, except for just two small differences. The most important of them is** hiding implementation details.**

A structure will by default not hide its implementation details from whoever uses it in code, while a class by default hides all its implementation details and will therefore by default prevent the programmer from accessing them.

**Members of a class are private by default and members of a structure are public by default.**

| **S. No.** | **Class** | **Structure** |
| --- | --- | --- |
| **1** | Members of a class are private by default. | Members of a structure are public by default. |
| **2** | It is declared using the **class** keyword. | It is declared using the **struct **keyword. |
| **3** | It is normally used for data abstraction and inheritance. | It is normally used for the grouping of different datatypes. |
| **4** | **Syntax:**<br>class class_name {<br>data_member;<br>member_function;<br>}; | **Syntax:**<br>struct structure_name {<br>structure_member1;<br>structure_member2;<br>}; |

Inheritance possible in both struct and classes!

*// C++ Program to demonstrate*

*// Inheritance with structures.*

#include *<iostream>*

**using namespace ****std**;

**struct ****Base **{

**public**:

int x;

};

*// is equivalent to*

*// struct Derived : public Base {}*

**struct ****Derived **: Base {

**public**:

int y;

};

int main()

{

Derived d;

*// Works fine because inheritance*

*// is public.*

d.x = 20;

cout << d.x;

cin.get();

**return **0;

}

Output = 20

In C: No, you cannot directly define functions inside a struct. However, you can define function pointers within a struct, which can then point to functions defined elsewhere.

In C++: Yes, you can define functions inside a struct, just like you can in a class. These are known as member functions.

C++

#include <iostream>

struct MyStruct {

int data;

void printData() {

std::cout << "Data: " << data << std::endl;

}

};

int main() {

MyStruct obj;

obj.data = 10;

obj.printData();

return 0;

}
