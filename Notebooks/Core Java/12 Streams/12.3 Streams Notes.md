# 12.3 Streams Notes

- Collection: Single unit of objects

- Stream: If we want to process the object from a collection, then we should use stream

Stream s = collection.stream();

Stream Operations

  - Filter

    - Filters the data from stream, and creates new stream (intermediate operation)

    - Stream filteredStream = originalStream.filter(element -> /\* predicate \*/);

    - It takes predicate as argument: functional interface / lambda expression, which returns Boolean types (true/false)

    - Input: 10 elements, Output: 0 to 10 elements
