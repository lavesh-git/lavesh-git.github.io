# 13.1 Serialization, Deserialization

Serialization and deserialization are fundamental concepts in Java that deal with converting objects into a storable or transmittable format and reconstructing them back into their original state.

**Serialization**

Serialization is the process of converting a Java object into a byte stream so that it can be:

  1. **Stored** in a file or database.

  1. **Transmitted** over a network.

  1. **Preserved** in a format suitable for later reconstruction.

**Key Points:**

  - **Why use serialization?**

    - To persist an object’s state.

    - To send objects over a network (e.g., via sockets or RMI).

  - **How is it achieved?**

    - By implementing the Serializable interface (marker interface) in the class.

    - Using ObjectOutputStream to write the object.

import java.io.\*;

class Person implements Serializable {

private static final long serialVersionUID = 1L; // Ensures compatibility during deserialization

String name;

int age;

Person(String name, int age) {

this.name = name;

this.age = age;

}

}

public class SerializationExample {

public static void main(String\[\] args) {

Person person = new Person("Alice", 25);

try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream("person.ser"))) {

oos.writeObject(person);

System.out.println("Object Serialized");

} catch (IOException e) {

e.printStackTrace();

}

}

}

**Deserialization**

Deserialization is the process of reconstructing a Java object from its byte stream representation.

**Key Points:**

  - **Why use deserialization?**

    - To restore an object's state from storage.

    - To reconstruct objects received over a network.

  - **How is it achieved?**

    - Using ObjectInputStream to read the byte stream and convert it back to an object.

import java.io.\*;

public class DeserializationExample {

public static void main(String\[\] args) {

try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream("person.ser"))) {

Person person = (Person) ois.readObject();

System.out.println("Object Deserialized");

System.out.println("Name: " + person.name + ", Age: " + person.age);

} catch (IOException | ClassNotFoundException e) {

e.printStackTrace();

}

}

}

**Differences between Serialization and Deserialization**

| **Feature** | **Serialization** | **Deserialization** |
| --- | --- | --- |
| **Definition** | Converts an object to a byte stream | Converts a byte stream back to an object |
| **Purpose** | Persist or transmit the object | Restore the object from its byte stream |
| **Key Classes Used** | ObjectOutputStream, FileOutputStream | ObjectInputStream, FileInputStream |
| **Direction** | Object → Byte Stream | Byte Stream → Object |

**Important Notes**

1. **serialVersionUID**:

  - A unique identifier for each serializable class.

  - Used to ensure that a deserialized object is compatible with the serialized version.

  - If not explicitly defined, the compiler generates one, but changes to the class structure can break compatibility.

1. **Transient and static variables**:

  - transient fields are not serialized.

  - static fields are class-level variables and are not part of the instance, so they are not serialized either.

1. **Not Serializable Exception**:

  - Thrown when attempting to serialize an object of a class that doesn’t implement Serializable.
