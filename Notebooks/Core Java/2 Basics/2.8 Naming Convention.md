# 2.8 Naming Convention

Naming convention of Java

Naming Convention in Java

Java naming conventions are guidelines to ensure clarity and consistency in code.

Common Conventions:

Packages: All lowercase.

Java

Copy

package com.example.myapp;

​

Classes/Interfaces: PascalCase(first letter of each word capitalized).

Java

Copy

public class MyClass { } public interface MyInterface { }

Methods/Variables: camelCase(start with a lowercase letter, capitalize subsequent words).

Java

Copy

public void calculateSum() { } int totalScore;

​

Constants: UPPER_CASEwith underscores.

Java

Copy

public static final int MAX_SIZE = 100;
