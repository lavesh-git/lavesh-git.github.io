# 3.1 Topics

**5. Methods**

**The **[method](<https://www.geeksforgeeks.org/methods-in-java/>)** is a collection of statements that accomplish some specific task and return the result to the caller**.

  - **Defining Methods**: Method declaration, parameters, return values.

  - **Method Overloading**: Same method name with different parameters.

  - **Method Parameters**: Pass-by-value, varargs.
