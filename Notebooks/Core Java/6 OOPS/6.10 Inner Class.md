# 6.10 Inner Class

**Inner class in Java**

  - What is Inner class in Java?
An **Inner Class** in Java is a class defined within another class. It is logically grouped to work with the outer class and has access to its methods and fields, including private members. Inner classes provide better encapsulation and help logically group classes that are used only in one place.

  - Properties of inner class

    1. **Access to Outer Class Members**:

      - Inner classes can access all members (fields and methods) of the outer class, even private ones.

    1. **Logical Grouping**:

      - Used to logically group classes that are only used by the outer class.

    1. **Encapsulation**:

      - Helps hide the implementation details from other classes.

    1. **Cannot Have Static Members**:

      - Non-static inner classes cannot declare static fields or methods.

    1. **Lifecycle**:

      - The lifecycle of the inner class is tied to the outer class. A non-static inner class requires an instance of the outer class to exist.

Instantiating inner class
To create an instance of an inner class, you first need an instance of the outer class. For static nested classes, no instance of the outer class is needed.

class OuterClass {

private String outerField = "Outer Field";

// Non-static inner class

class InnerClass {

void display() {

System.out.println("Accessing: " + outerField);

}

}

public static void main(String\[\] args) {

OuterClass outer = new OuterClass();

OuterClass.InnerClass inner = outer.new InnerClass();

inner.display();

}

}

Output: Accessing: Outer Field

- Types of inner class in Java
**1. Normal Inner Class
**A **normal inner class** is a non-static class defined within the body of an outer class. It has access to all members of the outer class, including private ones.
**Example:**

class Outer {

private String name = "Java";

class Inner {

void show() {

System.out.println("Outer class field: " + name);

}

}

public static void main(String\[\] args) {

Outer outer = new Outer();

Outer.Inner inner = outer.new Inner();

inner.show();

}

}

**2. Method-Local Inner Class**

A **method-local inner class** is defined within a method of the outer class. It is local to the method and can only be accessed within the method where it is defined.

**Example:**

class Outer {

void display() {

class MethodInner {

void show() {

System.out.println("Method-local inner class invoked.");

}

}

MethodInner inner = new MethodInner();

inner.show();

}

public static void main(String\[\] args) {

Outer outer = new Outer();

outer.display();

}

}

Method-local inner class invoked.

**3. Anonymous Inner Class**

An **anonymous inner class** is a class without a name. It is declared and instantiated in a single statement. It is commonly used to provide a quick implementation of an interface or an abstract class.

**Example:**

interface Greeting {

void sayHello();

}

public class Outer {

public static void main(String\[\] args) {

Greeting greeting = new Greeting() {

@Override

public void sayHello() {

System.out.println("Hello from anonymous inner class!");

}

};

greeting.sayHello();

}

}

Output:

Hello from anonymous inner class!

**4. Static Nested Class**

A **static nested class** is a static class defined within another class. Since it is static, it does not require an instance of the outer class to be instantiated. However, it can only access static members of the outer class.

**Example:**

class Outer {

static String staticField = "Static Field";

static class StaticNested {

void display() {

System.out.println("Accessing: " + staticField);

}

}

public static void main(String\[\] args) {

Outer.StaticNested nested = new Outer.StaticNested();

nested.display();

}

}

Output:

Accessing: Static Field
