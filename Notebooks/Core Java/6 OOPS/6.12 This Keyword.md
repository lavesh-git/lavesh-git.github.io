# 6.12 This Keyword

- This keyword
**this Keyword in Java
**The this keyword in Java is a reference variable that refers to the current object of the class. It is used in various contexts to avoid ambiguity or to clarify the code's intent.


**Common Uses of ****this**** Keyword
1. To Refer to the Current Class Instance
**When a local variable has the same name as an instance variable, this is used to distinguish between the two.
**Example:**

class MyClass {

private int value;

MyClass(int value) {

this.value = value; // 'this.value' refers to the instance variable

}

void display() {

System.out.println("Value: " + this.value);

}

public static void main(String\[\] args) {

MyClass obj = new MyClass(10);

obj.display();

}

}

Output:

Plain Text

Copy

Value: 10

**2. To Call Another Constructor in the Same Class**

this() is used to call a constructor from another constructor in the same class (constructor chaining).

**Example:**

class MyClass {

private String name;

MyClass() {

this("Default Name"); // Calls parameterized constructor

}

MyClass(String name) {

this.name = name;

}

void display() {

System.out.println("Name: " + name);

}

public static void main(String\[\] args) {

MyClass obj = new MyClass();

obj.display();

}

}

Output:

Plain Text

Copy

Name: Default Name

**3. To Pass the Current Object as a Parameter**

The this keyword can be used to pass the current object as a parameter to another method or constructor.

**Example:**

class MyClass {

void display(MyClass obj) {

System.out.println("Method called with: " + obj);

}

void callDisplay() {

display(this); // Passes current object

}

public static void main(String\[\] args) {

MyClass obj = new MyClass();

obj.callDisplay();

}

}

**4. To Return the Current Object**

The this keyword can return the current object from a method.

**Example:**

class MyClass {

MyClass getInstance() {

return this; // Returns the current object

}

void display() {

System.out.println("Current object: " + this);

}

public static void main(String\[\] args) {

MyClass obj = new MyClass();

obj.getInstance().display();

}

}

**Summary**

| **Use Case** | **Example** |
| --- | --- |
| Refer to current class instance | this.value = value; |
| Call another constructor | this(params); |
| Pass current object as a parameter | method(this); |
| Return current object from a method | return this; |

The this keyword enhances clarity and avoids ambiguity in class operations.

  - Difference between super and this
In object-oriented programming, especially in languages like **Java**, **C#**, and similar, super and this are two keywords that are often used for accessing members (methods, constructors, or variables) of classes. Here's the key difference between them:


**1. ****this**** Keyword:**

The this keyword is used to refer to the **current instance** of the class. It is commonly used to:

  - Access the current class’s instance variables.

  - Call the current class’s methods.

  - Pass the current object as a parameter.

  - Call one constructor from another within the same class.

**Examples:**

  1. **Accessing instance variables:**

class Example {

private String name;

public Example(String name) {

this.name = name; // Refers to the instance variable

}

}

Calling a constructor in the same class:

class Example {

public Example() {

this("Default Name"); // Calls the constructor with a parameter

}

public Example(String name) {

System.out.println(name);

}

}

**2. ****super**** Keyword:**

The super keyword is used to refer to the **immediate parent class** of the current object. It is commonly used to:

  - Access a parent class’s methods or variables when overridden in the child class.

  - Call a parent class’s constructor.

**Examples:**

  1. **Accessing parent class methods or variables:**

class Parent {

public void display() {

System.out.println("Parent Display");

}

}

class Child extends Parent {

public void display() {

super.display(); // Calls the parent class's display method

System.out.println("Child Display");

}

}

**Calling a parent class constructor:**

class Parent {

public Parent(String message) {

System.out.println(message);

}

}

class Child extends Parent {

public Child() {

super("Hello from Parent"); // Calls the parent class constructor

}

}

**Key Differences:**

| **Feature** | **this** | **super** |
| --- | --- | --- |
| **Refers to** | Current class instance. | Immediate parent class instance. |
| **Used in** | Accessing current class members. | Accessing parent class members. |
| **Constructor Call** | Calls another constructor in the same class. | Calls a constructor of the parent class. |
| **Scope** | Limited to the current class. | Refers only to the immediate parent class. |

In short:

  - Use this to work within the current class.

  - Use super to work with the parent class.
