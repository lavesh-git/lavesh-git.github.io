# 6.9 Final Keyword

- Final Keyword
**Final Keyword in Java
**The final keyword in Java is a modifier used to restrict the behavior of variables, methods, or classes. It enforces constraints on how these elements can be used or modified.

- Final Variable
**Final Variable
**A **final variable** is a variable that, once assigned a value, cannot be reassigned. This is used to create constants in Java.
**Rules:**

  1. **Must Be Initialized**:

    - A final variable must be initialized either at the time of declaration or in a constructor (for instance variables).

  1. **Cannot Be Modified**:

    - Once assigned, the value cannot be changed.
**Example:**

class FinalVariableExample {

final int CONSTANT = 100;

void display() {

System.out.println("Final variable value: " + CONSTANT);

// CONSTANT = 200; // Error: Cannot assign a value to final variable

}

public static void main(String\[\] args) {

FinalVariableExample example = new FinalVariableExample();

example.display();

}

}

Output:

Plain Text

Copy

Final variable value: 100

- Final Method
**Final Method
**A **final method** cannot be overridden by subclasses. This ensures the implementation of the method remains unchanged.
**Rules:**

  1. **Inheritance**:

    - A final method is inherited by subclasses, but it cannot be overridden.

  1. **Static Compatibility**:

    - Static methods can also be declared final to prevent method hiding.
**Example:**

class Parent {

final void show() {

System.out.println("This is a final method.");

}

}

class Child extends Parent {

// void show() { // Error: Cannot override final method

//     System.out.println("Attempting to override.");

// }

}

public class FinalMethodExample {

public static void main(String\[\] args) {

Child child = new Child();

child.show(); // Inherits the final method from Parent

}

}

Output: This is a final method.

- Final class
**Final Class
**A **final class** cannot be extended. This prevents inheritance and ensures that the functionality of the class cannot be altered by subclassing.
**Rules:**

  1. **No Subclassing**:

    - Declaring a class final ensures it cannot be subclassed.

  1. **Usage**:

    - Often used for utility classes (e.g., java.lang.String) or for security purposes.
**Example:**

final class FinalClass {

void display() {

System.out.println("This is a final class.");

}

}

// class SubClass extends FinalClass { // Error: Cannot inherit from final class

// }

public class FinalClassExample {

public static void main(String\[\] args) {

FinalClass finalClass = new FinalClass();

finalClass.display();

}

}

Output:

Plain Text

Copy

This is a final class.

**Key Characteristics and Differences**

| **Element** | **Usage** | **Restriction** |
| --- | --- | --- |
| Final Variable | To create constants | Cannot be reassigned once initialized. |
| Final Method | To prevent method overriding | Cannot be overridden by subclasses. |
| Final Class | To prevent class inheritance | Cannot be subclassed. |

**Example Demonstrating All Three**

final class FinalClassExample {

final int finalVariable = 10;

final void display() {

System.out.println("Final variable: " + finalVariable);

System.out.println("This is a final method in a final class.");

}

public static void main(String\[\] args) {

FinalClassExample example = new FinalClassExample();

example.display();

// example.finalVariable = 20; // Error: Cannot reassign final variable

}

}

Final variable: 10

This is a final method in a final class.
