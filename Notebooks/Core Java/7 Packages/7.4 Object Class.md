# 7.4 Object Class

Object Class **Object Class**: Methods provided by Object class like toString(), equals(), hashCode().

The statement Parent parent = new Child(); is an example of polymorphism where a parent class reference is used to refer to a child class object. This is often referred to as “**upcasting**” in Java.
