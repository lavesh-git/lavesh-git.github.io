# 9.3 Collection (Interface)

Collection nums = new ArrayList();

nums.add(6);

nums.add(5);

nums.add("5");

For(Object n : nums){

Int num = (Integer) n;

System.out.println(num);

}

Collection Interface by default works with Objects, and here the above code will give Runtime error because we have not specified the type of Object
