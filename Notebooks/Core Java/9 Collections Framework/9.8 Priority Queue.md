# 9.8 Priority Queue

- PriorityQueue
https://leetcode.com/problems/sort-characters-by-frequency/description/
Creating a Min and Max Priority Queue in Java involves using Java's built-in PriorityQueue class. Below, I’ll show you how to create both a Min Priority Queue and a Max Priority Queue.
**1. Min Priority Queue
**A Min Priority Queue is straightforward since Java’s PriorityQueue class is implemented as a min-heap by default.

import java.util.PriorityQueue;

public class MinPriorityQueue {

public static void main(String\[\] args) {

// Create a Min Priority Queue

PriorityQueue<Integer> minPQ = new PriorityQueue<>();

// Adding elements to the Min Priority Queue

minPQ.add(5);

minPQ.add(10);

minPQ.add(1);

minPQ.add(7);

// Printing the elements of the Min Priority Queue

System.out.println("Min Priority Queue: " + minPQ);

// Polling elements from the Min Priority Queue

while (!minPQ.isEmpty()) {

System.out.println("Poll: " + minPQ.poll());

}

}

}

**2. Max Priority Queue**

To create a Max Priority Queue, we need to pass a custom comparator to the PriorityQueue constructor that reverses the natural ordering.

import java.util.PriorityQueue;

import java.util.Collections;

public class MaxPriorityQueue {

public static void main(String\[\] args) {

// Create a Max Priority Queue

PriorityQueue<Integer> maxPQ = new PriorityQueue<>(Collections.reverseOrder());

// Adding elements to the Max Priority Queue

maxPQ.add(5);

maxPQ.add(10);

maxPQ.add(1);

maxPQ.add(7);

// Printing the elements of the Max Priority Queue

System.out.println("Max Priority Queue: " + maxPQ);

// Polling elements from the Max Priority Queue

while (!maxPQ.isEmpty()) {

System.out.println("Poll: " + maxPQ.poll());

}

}

}

**Explanation:**

  - **Min Priority Queue**:

    - By default, PriorityQueue in Java is a Min-Heap.

    - Elements are ordered according to their natural ordering, and the smallest element is at the head of the queue.

  - **Max Priority Queue**:

    - To create a Max-Heap, we pass Collections.reverseOrder() as a comparator to the PriorityQueue constructor.

    - This ensures that the largest element is at the head of the queue.

**Output:**

  - For the Min Priority Queue, the elements will be polled in ascending order.

  - For the Max Priority Queue, the elements will be polled in descending order.

This is a basic example, but you can extend these concepts to more complex data types by defining custom comparators.
