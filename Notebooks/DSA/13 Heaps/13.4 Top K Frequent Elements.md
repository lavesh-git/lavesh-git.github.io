# 13.4 Top K Frequent Elements

**Approach 0:** Frequency maintain using map, then store pairs in vector and sort the vector (on frequency), then pick the first k elements from the sorted vector.

SC: O(n) map + O(2n) store pairs + O(n) return array

TC: O(n) store in map + O(nlogn) sorting  + O(n) top K pick

**Approach 1: Using Heap**

**If we need top K elements then maintain a min heap of fixed size K, and if we find that the frequency of new pair**

```text
// (Using min-heap) - TC : O(nlog(n-k))

vector<int> topKFrequent(vector<int>& nums, int k) {
        // create pair {freq, val}
        typedef pair<int, int> p;
        //min-heap
        priority_queue<p, vector<p>, greater<p>> pq;

        //count frequency of each element
        // Worst Case - n distinct elements are stored, so, space O(n)
        unordered_map<int, int> mp;
        for(int i : nums){
            mp[i]++;
        }
        //Push in min-heap and maintain size k
        for(auto it:mp) {

            pq.push({it.second, it.first}); // {freq, val}

            if(pq.size() > k)
                pq.pop();
        }
        //Pick all top K elements
        vector<int> result;
        while(!pq.empty()) {
            result.push_back(pq.top().second);
            pq.pop();
        }
        return result;
    }
```
