# 13.5 Heaps

- Heap Sort

- Implement - Priority Queue

- Use Case - Data which need some priority

- A Binary heap is either Min Heap and Max Heap

- Binary Heap is a Complete Binary Tree. Completely filled till 2nd last level, and last level filled from left to right.

- Last level has all keys as left as possible.  Tightly packed filled so that array representaion is possible.

- It is stored as an Array. Internally, it is allocated/represented as an array.

- The array is level order traversal of tree representation of Heap.

- Root of Heap = arr\[0\]

For a node with index i:

  - Left Child = 2i + 1

  - Right Child = 2i + 2

  - Parent = \|(i-1) / 2\|

- BINARY HEAP IMPLEMENTATION:

  - We show heap as a tree, but we are implementing as an array, and modifying the array.

  - insert(int x), extractMin(), MinHeapify(), DecreaseKey(), BuildHeap(), getMin(), Delete()

  - Insert Functionality:

    - TC: O(height(binary tree)) = O(logN)

```text
void insert(int x){
        if(size == capacity) return;
        size++;
        arr[size -1] = x;

        for(int i = size -1; i!=0 && arr[parent(i)] > arr[i]){
            swap(arr[i], arr[parent(i)]);
            i = parent(i);
        }
    }
```

HEAPIFY ALGORITHM

  - Mainly used as a sub-routine in many standard operations.

  - Given a min/max heap with one possible violations (usually root). Fix min/max heap.

```text
void minHeapify(int i){
        int left = left(i);
        int right = right(i);
        int smallest = i;

        if(left < size && arr[left] < arr[smallest]) smallest = left;
        if( right < size && arr[right] < arr[smallest]) smallest = right;
        if( smallest != i) {
            swap(arr[smallest], arr[i]);
            minHeapify(smallest);
        }
    }
```

  - getMin, extractMin:

To extract, swap between arr\[0\] and last element arr\[size -1\]

```text
int extractMin(){ // TC: O(logN)
        if(size ==0) return INT_MAX;
        if(size ==1){
            size--;
            return arr[0];
        }

        swap(arr[0], arr[size -1]);
        size--;
        minHeapify(0);

        return arr[size];
    }
```
