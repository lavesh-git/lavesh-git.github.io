**TRIES - INTRODUCTION**

Every node of the trie can have atmax 26 children.

Technically, AR word is not added in the trie, but we can find it in ARE, which is why some nodes denoting the endpoints of words are made with darker circle.

  - A

  - AS

  - ARE

  - DO

  - DOT

  - NEW

  - NEWS

  - NO

  - NOT

  - ZEN

If we want to remove the word BED, we make the node D lighter, remvove dark circle

we should remove the D also but keep the E since it is required in BEND

Trie is better in space optimization as compare to hashmap and faster in searching also.

TRIE NODE:

```text
TrieNode{

char data;

// array to store address of all children -

TrieNode** children;

//  initialise in constructor: TrieNode** children = new TrieNode*[26];

// property to denote if ending word  -

bool isTerminal;

}
```

**TrieNode.h**

but initially no children so all pointers pointing to null

Trie.h

**Insert a word: **

If we need to insert string data then we ask root if there is any child with first letter of data, if it has then we recursively ask the first letter node to insert data\[1:\] in it, if it is not there then we create a new node and make it as a children. Base case: stop when data length is zero/ empty string and make that node terminal.
