# 16.3.1 Climbing Stairs

Count Number of Distinct Ways to Reach Nth Step from 0th Step

[Count Ways To Reach The N-th Stairs - Naukri Code 360](<https://www.naukri.com/code360/problems/count-ways-to-reach-the-n-th-stairs_798650>)

Identify DP:

  1. Count number of ways

  1. Min/Max number of ways

Try all possible ways (count, best way) -> Recursion

Count all ways = perform all ways, sum it up

Best way = perform all ways, tell the best
