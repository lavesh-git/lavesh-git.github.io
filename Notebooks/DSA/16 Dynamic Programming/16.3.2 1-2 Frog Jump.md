# 16.3.2 1-2 Frog Jump

[Frog Jump - Naukri Code 360](<https://www.naukri.com/code360/problems/frog-jump_3621012>)

Perform all ways, take out best possible (minimum energy).

Greedy doesn't work, perform Recursion/DP.

  1. Express as index (0 based indexing)

  1. 0,1,2,… n-1

  1. Perform All stuffs on that index

f(n-1) = min. energy reqd. to reach n-1 from 0

f(0) = 0

f(n) = min( f(n-1) + \[h(n) - h(n-1)\] , f(n-2) +  \[h(n) - h(n-2)\])

  1. Take the min(all stuff)

Recuurence solution:

```text
f(n){

if(n==0) return 0;

Left = f(n-1)  + abs(h[n] - h[n-1]);

If(n >1){
Right = f(n-2) + abs(h[n] - h[n-2]);
}

Return min(left, right);
```

}

Overlapping subproblems are present:

Memoization can be done. Draw recursion tree and find values, and overlapping subproblems.

Recurrence ---> DP

Trick for memoization = Look at the parameters which are changing. (n)

  1. Create dp array of size n + 1 --> dp\[n+1\]

  1. Before returning add it up

```text
f(n){

if(n==0) return 0;

Left = f(n-1)  + abs(h[n] - h[n-1]);

If(n >1){
Right = f(n-2) + abs(h[n] - h[n-2]);
}

Return dp[n] = min(left, right);
```

}

  1. Before calling any recursion, check if it has been pre-computed.

TC = O(N)

SC = O(N) + O(N)

Memoization (Top- Down) --> Tabulation (Bottom Up)

  1. See how much dp array used in memoization

Dp\[0\] = 0;
