# 2.5.10 Two Sum

TYPE 1:

Given an array of integers arr\[\] and an integer target. Return YES if there exist two numbers such that their sum is equal to the target. Otherwise, return NO.

TYPE 2:

Given an array of integers arr\[\] and an integer target. Return indices of the two numbers such that their sum is equal to the target. Otherwise, we will return {-1, -1}.

BRUTE FORCE:

BETTER: Using hashing
