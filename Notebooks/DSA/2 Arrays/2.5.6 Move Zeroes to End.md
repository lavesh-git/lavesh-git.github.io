# 2.5.6 Move Zeroes to End

[Leetcode 283. Move Zeroes](<https://www.youtube.com/watch?v=mgzcjQ1x9Mw>)

[Move Zeroes - LeetCode](<https://leetcode.com/problems/move-zeroes/>)

[Move all negative numbers to beginning and positive to end with constant extra space - GeeksforGeeks](<https://www.geeksforgeeks.org/move-negative-numbers-beginning-positive-end-constant-extra-space/>)

TC =  O ( 2N)

SC = O(1)

```text
vector<int> moveZeros(int n, vector<int> arr) {
    int count = 0;
    int i = 0, j = 0;
    for(int k=0; k < n; k++){
        if(arr[k] !=0){
            arr[i] = arr[k];
            i++;
        }
        else{
            count++;
        }
    }
    for(int j =0; j < count; j++){
        arr[n - count + j] = 0;
    }
    return arr;
}
```

BRUTE:

TC: O(n + x + n- 2)  = O(N)

SC: O(X)

where X is no. of zeros

OPTIMAL:

Swap zeros with non-zeros and push zeroes to end like this

TC: O(n)

SC: O(1)
