# 6.3.3 Ternary Search

[Ternary Search](<https://www.youtube.com/playlist?list=PL-Jc9J83PIiGiFr2WFAiS9nEssqEoCKC4>)

In binary search we have, high, low and mid = high + low / 2 pointer, and it requires array in sorted manner.

Binary = 2

Ternary = 3  i.e. divide array into three parts

m_1 = L + (R-L)/3

m_2 = L + 2(R-L)/3 = R - (R-L)/3

If element < arr\[m1\] then L = L and R = m1

If element > arr\[m2\] then L =m2 and R = R

Else L = m1 and R  = m2

Time Complexity:

Binary search -  1 . log_2 n

Ternary Search - 2 . log_3 n

Tenary search  has more time complexity than binary search.
