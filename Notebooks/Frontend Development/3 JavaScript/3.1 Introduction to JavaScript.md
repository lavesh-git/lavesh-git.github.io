# 3.1 Introduction to JavaScript

- Frontend & Webapps + Server & Backend -- Interactive effects within web browsers.

- Actions, Updates (alter page without reloading), Events (responds to user actions), Data (fetches and sends info to server)

- JS is an interpreted, high-level, dynamic programming language, means it is executed line-by-line. It is not compiled (compile means: whole code is converted to machine code).

- JS is synchronous, single threaded language.

  - HTML: Structure and Content

  - CSS: Appearance and Layout

  - JS: Interactivity and Dynamic Behaviour

- The programs in this language are called scripts. They can be written right in a web page’s HTML and run automatically as the page loads. Scripts are provided and executed as plain text. They don’t need special preparation or compilation to run.

## USE CASES:

  - Frontend Frameworks:

    - ReactJS - Library for building user interfaces

    - Angular - Mobile and Desktop Web Apps

    - Vue.js -  Progressive framework for user interfaces

  - Server Side Frameworks:

    - NodeJS: Allows JS to run on server (outside of web browser)

    - ExpressJS: minimal and flexible nodeJS web app framework

  - BuildTools (js based):

    - Webpack: module bundler for js apps

    - Parcel: fast, 0 config web app bundler

    - Gulp: automate tasks in dev workflow

  - Desktop Apps:

    - ElectronJS: cross platform desk-app (eg: ms teams)

  - Threejs - WebGL 3D Programming

  - WebRTC - enables peer to peer audio, video sharing

  - HowlerJS - JS audio library for web

## RUNTIME ENVIRONMENT:

  - Provides infrastructure to execute JS Code and it includes

    - **Core:** Includes a JS Engine (Google V8 for Chrome/Edge, SpiderMoney for Firefox etc)

    - **Browser Enviroment:** Offers APIs for DOM Manipulation (DOM, fetch, setTimeout, etc.), events and network requests.

    - **Asynchronous Support:** Handles non-blocking operations with event loops, callbacks, and promises.

    - Call Stack

The runtime environment is **not part of the JS language**. It’s the **ecosystem** around the engine that allows JavaScript to do things like make HTTP requests, handle user input, etc.

## JAVASCRIPT IN NODEJS

- **Nodejs**: Extends JavaScript capabilities to server-side programming.

  - Nodejs is open-source runtime environment for executing js code outside of a browser (different environment like server or computer)

  - Uses Chrome V8 JS Engine. Compiles JavaScript directly to native machine code. Just in Time Compilation. V8 uses C++.

  - V8 + Backend Features = NodeJS
