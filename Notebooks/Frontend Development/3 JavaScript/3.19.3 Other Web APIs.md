# 3.19.3 Other Web APIs

Section 2. Drag-and-Drop API

- [Drag and Drop API](<https://www.javascripttutorial.net/web-apis/javascript-drag-and-drop/>) – enable web applications to use the drag-and-drop feature in the web browsers.

- [FileReader API](<https://www.javascripttutorial.net/web-apis/javascript-filereader/>) – introduce the FileReader API and show you how to combine it with the Drag&Drop API to build an image upload application.

- [File and FileReader](<https://javascript.info/file>)

Section 3. Geolocation API

- [Geolocation API](<https://www.javascripttutorial.net/web-apis/javascript-geolocation/>) – Learn how to retrieve the users’ current locations.

Section 4. Notification API

- [Notification API](<https://www.javascripttutorial.net/web-apis/javascript-notification/>) – Learn how to display desktop notifications to users.

Section 5. History API

- [pushState](<https://www.javascripttutorial.net/web-apis/javascript-history-pushstate/>) – Learn how to use the history.pushState() method.

Section 7. Dialog & Popover API

- [Dialog API](<https://www.javascripttutorial.net/web-apis/javascript-dialog-api/>) – Show you how to use the HTML native element <dialog> to create a dialog and use the Dialog API to control the dialog visibility.

- [Popover API](<https://www.javascripttutorial.net/web-apis/javascript-popover/>) – Learn how to create popovers using Popover API.

Section 8. Canvas API

- [Basic Canvas](<https://www.javascripttutorial.net/web-apis/javascript-canvas/>) – Learn about the HTML5 <canvas> element and how to use the Canvas API to draw shapes.

- [Draw a filled rectangle](<https://www.javascripttutorial.net/web-apis/javascript-fillrect/>) – Show you how to draw a filled rectangle using the fillRect() method.

- [Draw an outlined rectangle](<https://www.javascripttutorial.net/web-apis/javascript-strokerect/>) – Learn how to draw an outlined rectangle by using the strokeRect() method.

- [Erase a rectangular area on a canvas](<https://www.javascripttutorial.net/web-apis/canvas-clearrect/>) – Show you how to use the clearRect() method to set pixels in a rectangular area to transparent black.

- [Draw lines](<https://www.javascripttutorial.net/web-apis/how-to-draw-a-line-in-javascript/>) – Draw a line from one point to another.

- [Draw text](<https://www.javascripttutorial.net/web-apis/javascript-filltext/>) – Show how to draw a text string onto a canvas.

- [Translate](<https://www.javascripttutorial.net/web-apis/javascript-translate/>) – Learn how to move the origin of the canvas to the new position.

- [Rotate](<https://www.javascripttutorial.net/web-apis/javascript-rotate/>) – Add a rotation transformation to rotate a drawing object.

- [Scale](<https://www.javascripttutorial.net/web-apis/javascript-scale/>) – Add a scaling transformation to the canvas units horizontally and/or vertically.
