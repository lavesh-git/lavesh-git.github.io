# 5.10 Styling in React

In React, you specify a CSS class with className. It works the same way as the HTML class attribute, and then we write CSS rules separately:

<img className="avatar" />

/\* In your CSS \*/

.avatar {

border-radius: 50%;

}

Build process supports imports like

**Import"./index.css" ;**

**Import reactImg from './assets/react-core-concepts.png';**

Files included here are present in the final deployable files after build process.
