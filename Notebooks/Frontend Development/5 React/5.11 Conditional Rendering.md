# 5.11 Conditional Rendering

[Conditional Rendering in React \|\| React Series 2024](<https://www.youtube.com/watch?v=OjF-OwLOKYE&list=PL9i39jUQljInNAIHUnnZhKrYhLbFt5I_6&index=7&pp=iAQB0gcJCckJAYcqIYzv>)

In React, there is no special syntax for writing conditions. Instead, you’ll use the same techniques as you use when writing regular JavaScript code. "If" doesn't work insiode JSX:

let content;

if (isLoggedIn) {

content = <AdminPanel />;

} else {

content = <LoginForm />;

}

return (

<div>

{content}

</div>

);

For compact code use, conditional operator (?). It works inside JSX:

condition ? exprIfTrue : exprIfFalse

<div>

{isLoggedIn ? (

<AdminPanel />

) : (

<LoginForm />

)}

</div>

When you don’t need the "else" branch, you can also use a shorter logical && syntax:

short-circuit operator -->  if any falsy, return falsy

<div>

{isLoggedIn && <AdminPanel />}

</div>
