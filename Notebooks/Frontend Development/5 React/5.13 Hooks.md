# 5.13 Hooks

- Functions starting with use are called Hooks.

- Hooks are more restrictive than other functions. You can only call Hooks at the top of your components (or other Hooks).

- React provides some functionality by default. Hooks are way to hook onto that functionality provided by react.

- Built-in Hooks: useState - State Management.
