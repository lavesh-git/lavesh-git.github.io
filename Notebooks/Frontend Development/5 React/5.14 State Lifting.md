# 5.14 State Lifting

[State Lifting in React 2024 || Episode #65](<https://www.youtube.com/watch?v=Z4hN0WZbASk&list=PL9i39jUQljInNAIHUnnZhKrYhLbFt5I_6&index=6&pp=iAQB>)

Sharing data between components:

export default function MyApp() {

const \[count, setCount\] = useState(0);

function handleClick() {

setCount(count + 1);

}

return (

<div>

<h1>Counters that update together</h1>

<MyButton count={count} onClick={handleClick} />

<MyButton count={count} onClick={handleClick} />

</div>

);

}

function MyButton({ count, onClickFn }) {

return (

<button onClick={onClickFn}>

Clicked {count} times

</button>

);

}

MyApp (parent) component contains the count state and the handleClick event handler, and passes both of them down as props to each of the buttons (child component). When button is clicked, onClick = handleClick is fired and count is updated and passed as prop to each button. This is called “lifting state up”. By moving state up, you’ve shared it between components.
