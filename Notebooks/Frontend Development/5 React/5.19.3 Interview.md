# 5.19.3 Interview

**🔹 Topics Discussed**

  - Controlled vs Uncontrolled components (state ownership in forms)

  - Difference between useEffect and useLayoutEffect

  - useMemo vs useCallback

  - React.memo vs useMemo

  - React Fiber, reconciliation, and diffing

  - Batching of state updates in React (React 18)

  - Best practices for using useEffect (mount, update, cleanup)

  - Writing a custom useFetch hook using useCallback

  - State management decisions (single global store vs multiple stores)

**🔹 Key Takeaways**

Interviewers focus more on practical understanding than memorized definitions.

Knowing why and when to use hooks (useCallback, useMemo) matters more than just syntax.

Missing a few theoretical concepts (like batching or PureComponent) is not a deal-breaker if you show strong real-world experience.

Structured answers (definition → use case → example) significantly improve communication.
