## Quick capture

Open this week's note and add a row to **Discoveries**. Fill in the question, subject, source, tags, and related notebook notes. Update Status as you study.

For a new week, create a note under **Study Hub/Weeks** named like **2026-W46**, then insert **Templates → Weekly Review**. The website discovers weekly notes automatically; this local list is optional.
